# Student Grade Tracker (Java)

Console-based Java program to manage student grades.

## Features
- Add, view, update and delete students
- Average, highest and lowest score
- Summary report of all students
- Input validation

## Tech
- Java, ArrayList, OOP (Student class)

## How to run
## How to run

1. Clone the repo:
```
git clone https://github.com/rohanshxrma/Student-Grade-Tracker-In-Java.git
cd Student-Grade-Tracker-In-Java
```

2. Compile:
```
javac *.java
```

3. Run:
```
java StudentGradeTracker
```
